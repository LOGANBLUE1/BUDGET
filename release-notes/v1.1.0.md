Budget 1.1 makes adding expenses faster and adds ratings, categories and an optional
Google Drive backup. Everything still works fully offline; the backup is off until you
sign in and turn it on.

## What's new

- **Amount-first expenses**: the add dialog opens on the amount with the number keyboard.
  The amount is the only required field. The name is optional, and an expense without
  one shows as *Expense*.
- **Star ratings**: an optional 1–5 ★ rating on each expense, plus an overall rating on
  each budget (handy for rating a whole trip). Stars show on expense rows, budget cards
  and the budget summary. Tap the selected star again to clear it.
- **Categories**: optional categories such as *Food* or *Stay*, shared by all budgets.
  Pick one from the chips in the expense dialog, or tap **New** to create one right there.
  A new **Categories** screen (tag icon on the home screen) shows how many expenses use
  each one and lets you add, rename or delete them. Deleting a category keeps its
  expenses; they just become uncategorised.
- **Google Drive backup & sync**: a new **Backup & sync** screen (cloud icon on the home
  screen). Sign in with Google and switch on sync, and every change is backed up a few
  seconds later. **Back up now** and **Restore** are there too. On a fresh install the app
  offers to restore if it finds a backup. The backup is a single file in Drive's hidden
  app-data folder, and the app can't see any of your other Drive files. An empty phone
  never overwrites an existing backup.

## Upgrading from 1.0

Install over 1.0; your budgets and expenses are kept. The database is upgraded in place
(schema v2 → v4).

The app now requests the **internet permission**. It's used only by the optional Google
Drive backup; nothing is sent anywhere unless you sign in and turn sync on.

## Install

Download `budget-v1.1.0.apk` below and open it on the device. Android will ask you to
allow installing from this source, since it isn't from the Play Store.

Requires **Android 8.0 (API 26)** or newer. Signed with the project release key; the APK
is not debuggable.

## Google Drive setup

Google sign-in only works for builds whose package name and signing-certificate SHA-1 are
registered as an Android OAuth client in Google Cloud. See **Google Drive setup** in the
[README](https://github.com/LOGANBLUE1/BUDGET#google-drive-setup-one-time). Everything
else in the app works without it.

## Build from source

Requires JDK 17 and the Android SDK (platform 35).

```sh
./gradlew installDebug      # build and install on a connected device
./gradlew testDebugUnitTest # unit tests
```

## Under the hood

Room schema v4 (v2 → v3 adds ratings, v3 → v4 adds categories with
`ON DELETE SET NULL`). Backup uses the Google Identity `AuthorizationClient` with the
`drive.appdata` scope, the Drive REST v3 API, WorkManager for debounced uploads that retry
when you're offline, and kotlinx.serialization for the backup format. Older backups stay
readable as the format grows.
