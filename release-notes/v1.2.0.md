Budget 1.2 lets you close finished budgets, log expenses faster and see where
the money went. It installs over 1.1.0 as a normal update and keeps your data.

## What's new

- **Close and re-open budgets**: the home screen now has two tabs, **Live** and **Closed**.
  Tap a tab or swipe between them. Close a budget from its ⋮ menu (or inside it) when
  you're done with it. It moves to the Closed tab with its expenses and becomes read-only.
  Re-open it any time from the same menu or the banner inside it. Both show an **Undo**.
- **Expense dates**: the add and edit dialogs have a **Date** field. It's today unless you
  pick an earlier day, so you can log yesterday's taxi. Expense rows now show the date only.
- **By category**: a card inside each budget shows how much went to each category, as an
  amount, a percentage and a bar. Tap a category to show only its expenses. Tap the
  card's header to collapse it to a one-line summary, and again to expand it.
- **Faster logging**:
  - a **+** on each live budget card adds an expense without opening the budget;
  - long-press the app icon for an **Add expense** shortcut to the budget you last used;
  - the add dialog opens with the number keyboard ready.
- **Backup file**: in **Backup & sync**, **Export** saves everything to a file you choose
  (the same format as the Drive backup), and **Import** loads one. Import replaces
  everything on the phone, after showing what the file contains. No sign-in needed.

## Upgrading from 1.1.0

Install it over 1.1.0; your data stays. The database is upgraded in place (schema v4 → v5,
which adds one column for closed budgets). Backups made by 1.1.0 still restore, with every
budget live.

Upgrading from 1.0? See the [1.1.0 notes](https://github.com/LOGANBLUE1/BUDGET/releases/tag/v1.1.0):
1.0 used a different signing key, so it has to be uninstalled first.

## Install

Download `budget-v1.2.0.apk` below and open it on the device. Android will ask you to
allow installing from this source, since it isn't from the Play Store.

Requires **Android 8.0 (API 26)** or newer. Signed with the project release key
(certificate SHA-1 `2E:52:24:4A:58:54:F3:2D:C4:96:13:B1:EB:3F:8A:90:E2:E3:70:72`).
